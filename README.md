# Tyler's Medical Care Portal

A comprehensive web application for managing Tyler's cardiac care, medications, supplements, and monitoring schedule.

## Features

- **Dashboard Overview**: Health status, daily tasks, and recent alerts
- **Medication Management**: Detailed information about each medication and scheduling
- **Herbal Supplements**: Information about supplements and their interactions
- **Nutrition & Diet**: Specialized cardiac care meal plan
- **Interaction Management**: Visualization of drug and herb interactions
- **Monitoring Plan**: Daily, weekly, monthly, and quarterly monitoring schedules
- **Treatment Optimization**: Recommendations for improving Tyler's care
- **Educational Resources**: Information about cardiac care and medications

## Technologies Used

- HTML5
- CSS3 (with Bootstrap 5)
- JavaScript (with Chart.js for data visualization)
- Font Awesome for icons
- Google Fonts for typography

## Getting Started

1. Clone or download this repository
2. Open `index.html` in your web browser
3. Navigate through Tyler's medical information using the sidebar menu

## Usage

- Use the sidebar to navigate between different sections of Tyler's care plan
- The dashboard provides an overview of Tyler's current status and daily tasks
- Click the "Emergency Contact" button for urgent veterinary assistance
- All information is organized by category for easy access

## Customization

To customize this portal for another pet:

1. Replace all instances of "Tyler" with your pet's name
2. Update medication information in the "Medications" section
3. Modify supplement details in the "Herbal Supplements" section
4. Adjust the nutrition plan in the "Nutrition & Diet" section
5. Update monitoring schedules in the "Monitoring Plan" section
